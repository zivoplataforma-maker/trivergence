# Plan maestro

Trivergence es un orquestador de ingeniería con IA, local-first y orientado a
Windows. Parte de un objetivo, elige una estrategia, construye un plan y
coordina la ejecución con permisos, presupuesto y evidencia verificable.

El alcance inmediato es consolidar el núcleo de orquestación P3 y sus garantías
de recuperación. La aplicación de escritorio es el punto de entrada. La
expansión de proveedores se decide por integración y por capacidad, según los
[documentos de proveedores](providers/) y los criterios del
[roadmap](../ROADMAP.md).

El éxito del siguiente incremento se mide por pruebas del recorrido desde el
objetivo hasta el resultado, evidencia persistida y verificación de que la
recuperación conserva el estado ante cancelaciones o interrupciones. El
[estado actual](ESTADO_ACTUAL.md) distingue el historial Git del trabajo local.
