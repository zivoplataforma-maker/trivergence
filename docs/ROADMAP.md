# Hoja de ruta operativa

El [roadmap principal](../ROADMAP.md) conserva el detalle y los criterios por
fase.

| Prioridad | Trabajo                                                                                 | Criterio de finalización                                                             |
| --------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 1         | Validar los cambios locales de deliberación y su integración con runtime y persistencia | Casos focalizados y validación general ejecutados, con resultados registrados        |
| 2         | Verificar el recorrido de escritorio para los cambios de P3                             | Flujo de ejecución, aprobaciones y recuperación comprobado en Windows                |
| 3         | Evaluar las rutas externas según su documentación                                       | Capacidad, permisos, datos, coste y evidencia definidos antes de habilitar cada ruta |

La validación en escritorio requiere un entorno Windows. El uso de rutas
externas depende de las garantías y autorizaciones de cada integración.
