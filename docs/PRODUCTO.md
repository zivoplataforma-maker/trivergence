# Producto

Trivergence está dirigido a personas que necesitan coordinar tareas de
ingeniería con IA y conservar control sobre los efectos de la ejecución. Mission
Control, en la aplicación Electron, organiza el trabajo alrededor del objetivo,
el plan, las aprobaciones y el historial.

| Interacción                                               | Resultado esperado                                 |
| --------------------------------------------------------- | -------------------------------------------------- |
| Describir un objetivo y seleccionar un espacio de trabajo | Obtener un plan con pasos y alcance identificables |
| Revisar una ejecución con permisos o efectos              | Poder inspeccionarla y aprobarla según política    |
| Consultar una ejecución previa                            | Recuperar estado, resultados y evidencia           |
| Configurar proveedores                                    | Ver capacidades y restricciones de cada ruta       |

La experiencia con múltiples proveedores depende de los criterios de
habilitación documentados en [providers](providers/). Los detalles de UX y
entregas están en [product](product/) y [design](design/).
